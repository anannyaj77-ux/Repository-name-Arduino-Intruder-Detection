# Arduino Intruder Detection

An Arduino-based intruder detection system that senses motion and triggers an alarm to alert users of unauthorized entry.

## Files
- `sketch.ino` – main Arduino code
- `diagram.json` – circuit diagram for the Wokwi simulator
- `libraries.txt` – libraries used by the project
- `wokwi-project.txt` – Wokwi project link/info

## How to run
1. Open [wokwi.com](https://wokwi.com) and create a new Arduino project.
2. Paste the contents of `sketch.ino` and `diagram.json` into the editor.
3. Click the green Start button to run the simulation.
